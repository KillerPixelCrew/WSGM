# Contract and ownership

LibHandheld public contracts describe semantic capability values, exact identity, controller and
motion samples, haptic output and typed operation outcomes. WSGM owns user profiles, virtual
targets, input leases and both UI surfaces. Internal family engines and transport types remain
private.

Detection is pure and exact. Create uses the selected definition, captured identity, caller-owned
state directory and per-instance diagnostics. Start opens only supported native sources and degrades
independent services independently. Stop and suspend own bounded restoration; dispose frees handles.
Every publication and command belongs to the current lifecycle. No input or state publishes after
stop, suspend or disposal.

Serialize actual transport operations once. Reject cancellation before dispatch; submitted failures
are uncertain and never automatically retried. Read failures leave observations unknown and do not
disable source-supported controls. Publish successful writes as observed. Keep recovery records
bound to exact model and firmware and preserve old state paths/formats during migration.

A physical-source disconnect releases all held state. Hooks preserve press/release symmetry, pass
injected events through and allocate/log nothing per sample. Family contributor guides are the
source of truth for Claw power/chord and Ally controller-table/ATKACPI invariants.
