# Settings UI, themes and backdrop library: plan and code review

Domain: `src/WSGM/Settings/**` (30 C# files, 13 XAML), `src/WSGM/Themes/**` (1 C#, 6 XAML),
`src/Avalonia.LiveBackdrop/**` (2 C#, native C++, build script, README), `tests/Avalonia.LiveBackdrop.Tests/**`,
`tests/WSGM.Tests/Settings/**`, `tests/WSGM.Tests/Themes/**`, `tests/WSGM.UiTests/Settings/**` and the Settings part of
`tests/WSGM.UiTests/Infrastructure/UiFixture.cs`. Baseline `master` 1329813f. Every non-generated source file in scope
was read in full; callers were traced into Shell, Overlay, Core, App and tools.

Context: the prior Claude audit units for this domain (U13A-SUI, U13B-SUI, U13C-SUI) were never started
(`audit-coverage.md:413-440`), A01 lists the whole domain as remaining scope (`audit/A01/remaining-scope.json`), and
AF02 holds it as future closure work. The ledger has only four entries that touch this domain: U04A-LFA-004,
U04A-LFA-010, U04A-LFA-028 and U05-LFB-005 (= PV11-005). None of the seven admitted batches (W02_01, W02_02, T01_01,
A02_01..A02_04) touches this domain; W02_01's EDID flag fix is consumed by `SettingsViewModel.MergeCatalog` and is
compatible (identity match is path-first, `existing.Target = observed.Target` only upgrades after a match).
